## What changed

Finishes PLAY-023: levels and the last language now follow the account, per language.

- **Guest levels survive sign-in (F5).** At sign-in, every language with no `language_settings` row gets the device's level (`parlaplay.level.{code}`, default 1) saved to the account. A guest who picked Level 2 in Chinese keeps it. Where a row exists, the row wins and is copied to the device, as before. The upsert uses `ignoreDuplicates`, so a row another device saved meanwhile is kept. If reading the rows fails, nothing is uploaded.
- **Reading the last language at sign-in (spec 2).** A device with no last language (neither in the shell nor in the `app` key) takes `profiles.last_language` as `serverLast`. A device that has one keeps it and never asks. The request gives up after 3 seconds so a slow connection doesn't hold up sign-in or the save-guest prompt. Unknown or empty values are ignored.
- **Writing the last language (spec 6.3).** The shell's `writeProfile` effect, which did nothing before, now updates `profiles.last_language` when a signed-in player chooses a language. It's best effort; the device's `app` key is what counts on this device.
