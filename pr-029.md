## What changed

Brings the merged parlaplay app to `main`: Chi è? and Shéi in one repo, one shell that routes by language, and every piece of per-language data kept apart. Each part was reviewed in its own PR into `play-029-shell-reducer` (#69 to #77).

Despite the branch name, PLAY-029 (one Settings page with per-language sections) is not in this PR.

### One repo for both games (#69)

- **PLAY-011:** Italian moves into `src/languages/it`, shared code into `src/core`.
- **PLAY-012:** Shéi comes in with its history, moved into `src/languages/zh` first.
- **PLAY-013:** the shared code both games changed is reconciled into one core. The leftover placeholders in the old `src/services` and `src/store` are removed.

### The shell and routing (#70, #71)

- **PLAY-015:** `languages.json` is the language registry, checked with Zod, with each content version copied in at build time.
- **PLAY-016:** the `LanguageModule` contract, with both languages implementing it.
- **PLAY-017 and PLAY-018:** a pure shell reducer in `src/core/state` (no React, DOM, network or clock, enforced by a lint rule), with unit tests for every cell and fast-check tests for the 4.4 invariants.
- **PLAY-019:** each language's module loads with `import()` on its first visit, and the bundle check covers it.
- A first visit to `/` opens the picker at `/languages`. Chi è? is at `/it` and Shéi at `/zh`. The desktop nav's Play goes to the game before starting a round.

### Per-language data (#72 to #77)

- **PLAY-021:** migration 1 adds the `languages` table, a `language` column on every per-language table, `language_settings` and `profiles.last_language`. A `review_log` row may only point at a game of its own language.
- **PLAY-020 and PLAY-023:** device storage keys carry the language code, with one progress store and one level per language. Sync sends each row's language, a pull gives each store only its own rows, and each language's cards are replayed from its own log. Guest levels survive sign-in, and the last language follows the account.
- **PLAY-025:** one save-guest prompt naming every language with guest data, and sign-out that clears every language.
- **PLAY-026:** fast-check separation tests across storage, sync merge, replay and the Progress selectors (3.4.1, 3.4.2).
- CI: generated planning files are skipped in the format check.

Not in this PR: PLAY-022 (migration 1 on staging) and PLAY-024 (the Chi è? compatibility test).
